
# AI Test Case Generator Agent

An AI-powered web application that generates software test cases
from plain-language requirements.

## Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- LangChain
- SQLite
- Pandas

## Features

- Requirement understanding
- Positive test case generation
- Negative test case generation
- Edge case generation
- Priority assignment
- Edit and delete test cases
- SQLite history
- CSV export

## Run the Application

Install dependencies:

pip install -r requirements.txt

Start Ollama:

ollama serve

Run the application:

streamlit run app.py
